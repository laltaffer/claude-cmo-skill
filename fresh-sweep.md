# Fresh Sweep — catching tropes that didn't exist last month

AI tells are not a fixed list. Wikipedia's "Signs of AI writing" documents vocabulary
shifting between model eras ("delve" marked the 2023–24 era; each generation mints new
tells), and public pattern-spotting moves faster than any static catalog. The catalog in
[voice-and-tropes.md](voice-and-tropes.md) is a snapshot; **the sweep is the
discipline.**

Run at every REVIEW stage. Timebox: ~5 minutes. If sources are unreachable, note it in
the findings and proceed with the static catalog — never silently skip.

## Protocol

1. **Re-check the living catalogs:**
   - https://tropes.fyi/tropes-md — community-maintained trope directory
   - https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing — editor-maintained,
     model-era aware
2. **Search current chatter** (WebSearch; date the queries deliberately — month
   granularity for the fast-moving writing-tells discourse, year for the slower
   marketing-slop discourse):
   - "AI writing tells <month> <year>"
   - "AI slop marketing <year>"
   - Skim any surfaced HN / r/marketing / X threads — these communities name new tells
     months before the catalogs do.
3. **Diff against the catalog.** A pattern counts as a new tell when it recurs across
   **two independent sources** (not one viral post) or when you notice it in the draft
   *and* one source names it.
4. **Append, dated, to the changelog** in voice-and-tropes.md — pattern, one-line
   description, source. Promote it into the Hard bans or Density tells section if it
   keeps hitting in later sweeps.
5. **Scan the draft** against static catalog + new finds together.

## Sweep the reverse direction too

Tells decay into false positives. When a pattern gets so publicly associated with AI
that humans get accused over it (the em-dash discourse), the risk inverts: scrubbing
every em dash to appease detector-brained readers strips voice without adding
authenticity. When a sweep shows a tell has crossed into folk-detector territory, note
that in the changelog — the standard stays "would a specific human say this," not
"would a detector pass this."

## Beyond prose

Watch for emerging **format and channel tropes**, not just words: AI-shaped landing
pages (identical section rhythms), AI-voice video narration patterns, LinkedIn-post
skeletons ("I did X. Here's what it taught me: 🧵"), AI-generated ad aesthetics. Prose
finds go in voice-and-tropes.md; visual finds get flagged to the design skills.
